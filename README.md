# Cyberpunk AMD Optimizer

Optimiseur **Cyberpunk 2077** pour configurations **AMD** (Radeon + Ryzen), avec un thème Night City.

> Cyberpunk 2077 est un jeu **solo, sans anti-triche** — cet outil ne présente aucun risque de bannissement.

## Fonctionnalités

- 🎚️ **Préréglages** Qualité / Équilibré / Perf (+ ton préréglage perso), avec **aperçu** avant application
- 📥 Import automatique de tes réglages du jeu au démarrage
- ⛭ Éditeur complet des réglages graphismes/vidéo (descriptions détaillées, impact FPS)
- 📊 Monitoring **FPS / températures** en direct + **benchmark** avant/après
- 🖥️ **Overlay en jeu** (FPS / temp GPU / CPU)
- 🗂️ Gestionnaire de **sauvegardes** de ta config (restauration 1 clic)
- ⚙️ **Tweaks système** à la carte (priorité CPU, Game Mode, HAGS, GPU hautes perfs, plein écran off…)
- 🔄 **Mises à jour automatiques**

## Installation

Télécharge le dernier installeur dans **[Releases](../../releases/latest)** :
`Cyberpunk-AMD-Optimizer-Setup-x.y.z.exe`

L'application se met ensuite **à jour toute seule** depuis les prochaines Releases.
